¿Qué es el Desarrollo Web?

El desarrollo web es el proceso de crear sitios que ves todos los días en Internet. Estos sitios están hechos con código y funcionan dentro de un navegador.

¿De qué está hecho un sitio web?

En general, podemos pensar que todo sitio web tiene tres partes principales:

  • Contenido: texto, imágenes, enlaces, videos.
  • Estructura: cómo se organiza el contenido en la página.
  • Estilo: colores, tamaños, fuentes y posiciones.

HTML y CSS

Para construir un sitio web usamos principalmente dos lenguajes:

  1. HTML (HyperText Markup Language): define la estructura y el contenido.
  2. CSS (Cascading Style Sheets): define el diseño visual y los estilos.

En este ejemplo solo estamos usando HTML para mostrar el contenido. Más adelante, agregaremos CSS para hacer que esta página sea más atractiva visualmente.
